# Contributing

BurnLens Experiment Four uses evidence-bound, issue-backed changes.

1. Read `AGENTS.md`, the execution goal, current status, project-control
   profile, and active milestone.
2. Work only inside an authorized dependency-ready evidence unit.
3. Use `codex/` branches and pull requests after the initial unborn-main
   bootstrap exception.
4. Keep scientific bytes, secrets, private review material, runtimes, and
   generated outputs outside Git.
5. Preserve failed and superseded attempts and keep claims bounded to evidence.
6. Run `python scripts/validate_repository.py` and the test suite before review.

Changes to scientific scope, cohort rules, source adoption, reference meaning,
test opening, or release require the declared owner gate.
