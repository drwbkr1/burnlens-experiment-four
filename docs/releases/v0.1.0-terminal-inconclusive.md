# BurnLens Experiment Four v0.1.0 terminal evidence release

## Outcome

BurnLens Experiment Four closes its data route `INCONCLUSIVE` at Milestone 1.
The complete frozen metadata universe contains 187 accounted candidates, but
the bounded 1,756-feature WFIGS snapshot has zero non-null values for the exact
reviewed final-acre field. Independent replay therefore verifies a maximum of
zero selectable slots versus 36 required.

## Separate terminal states

- Dataset readiness: `NOT_EVALUATED`
- Lifecycle status: `INCONCLUSIVE`
- Comparative status: `NOT_EVALUATED`
- Release status: `NOT_RELEASED` until exact owner approval and live release
  verification

The engineering controls for metadata capture, identity reconciliation,
complete-universe accounting, deterministic evaluation, and independent replay
pass. That engineering result does not convert the missing source evidence into
scientific eligibility.

## What this release contains

- public protocols, authority, milestone, decision, and evidence records;
- the exact representation-only amendment and aggregate approval consequence;
- deterministic WFIGS capture, MTBS/WFIGS reconciliation, universe building,
  independent validation, and full-repository replay packaging code;
- tests and public-safe limitations needed to reproduce the terminal result.

## What this release does not contain

It contains no source bodies, private review responses, credentials, imagery,
reference labels, candidate or role selections, AOIs, models, predictions,
metrics, or sealed test evidence. Milestones 2 through 7 were not authorized.

## Limitations

This result does not show that no qualifying fires existed. It shows that the
exact frozen source package could not establish even one selectable event under
the reviewed rules. Substituting another acreage field, source, threshold,
cohort, year, state, or prior event would define a different experiment.

The project is not field validation, dense ground truth, population-wide burn
severity evidence, calibrated operational accuracy, emergency guidance, or a
production wildfire product.
