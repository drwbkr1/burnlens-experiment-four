# 2026-08-25 — Prior-event exclusions

Milestone 1 began with a read-only inventory of prior BurnLens event exposure.
Experiment One public `main` supplied six accepted whole-event identities.
Experiment Three release `v1.0.0` was checked independently and used exactly
those same six events, adding none.

Experiment Two's public branch contains only a blocked empty inventory. Its
local checkout is heavily dirty and includes unpublished continuation records,
so those records were not promoted to accepted truth. Three exact, hash-bound,
model-blind candidate rosters were nevertheless used for conservative
freshness protection: 24 WFIGS rows, 24 BAER-backed rows, and 18 HLS-fresh rows
collapsed to 62 unique publisher identities. All 62 are permanently excluded,
along with the six Experiment One/Three events, for a total of 68.

This unit opened no scientific source body and adopted no external source. It
does not select or imply eligibility for any Experiment Four event.
